# PayFlow - Installment Payments Platform

Go, MySQL, React, TypeScript, Docker, GitLab CI/CD, Kubernetes, Prometheus, Grafana

- Built a Go REST API for installment plans, payments, refunds, and paginated transaction history using MySQL transactions, row locks, validation, and persistent idempotency keys.
- Developed a typed React SPA and automated unit, MySQL integration, component, and Playwright test suites, with Dockerized local services and Prometheus/Grafana observability.

## LinkedIn Project Description

PayFlow is an educational installment-payments platform focused on financial consistency. It models orders, payment plans, exact minor-unit installment splits, idempotent payment retries, partial refunds, and transaction history. The monorepo includes a Go/MySQL API, React/TypeScript SPA, automated tests, Docker Compose, GitLab CI, Kubernetes fundamentals, and a provisioned Prometheus/Grafana monitoring stack.
